# 硬件 BOM

| 档位 | 配置 | 价格 | 能力 |
|---|---|---|---|
| 最低 | Orange Pi Zero 3 2GB / 32GB / Wi-Fi | 150–200 元 | agent + 文件 + 无头浏览器（慢） |
| **推荐** | Orange Pi Zero 3 4GB / 64GB / 4G Cat.4 / 10,000mAh | 280–400 元 | 全部 + 语音 + 多任务 |
| 带屏 | 上面 + 3.5" SPI 屏（LVGL 状态页） | +60–80 元 | 脱离手机的独立形态 |

## 配件

- 4G：EC200A Cat.4（USB/mini-PCIe），需 quectel 驱动；
- 供电：充电宝主板 + UPS 模块，支持边充边用；
- 外壳：3D 打印（STL 待补），金属壳兼作散热；
- 麦克风/喇叭：USB 声卡或 I2S。
