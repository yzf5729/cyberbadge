# 架构

```
┌────────────┐   WebSocket/HTTP    ┌──────────────────────────┐
│ 手机浏览器  │ ◀────────────────▶ │ 设备端 device/ (Linux)   │
│ PWA 借屏    │                     │  agent 循环 + 文件/浏览器 │
└────────────┘                     │  SQLite 记忆 + 任务队列   │
                                   └──────────┬───────────────┘
                                              │ HTTPS（设备 token）
                                   ┌──────────▼───────────────┐
                                   │ 网关 gateway/ (VPS)      │
                                   │ 鉴权/配额/Key/多供应商   │
                                   └──────────┬───────────────┘
                                              │
                                   ┌──────────▼───────────────┐
                                   │ 云端 LLM API（OpenAI 兼容）│
                                   └──────────────────────────┘
```

## 数据流

1. 手机打开 `http://设备IP:8000`，WebSocket 连接 `/ws`；
2. 用户发消息 → 设备端 `agent.chat()` 调网关 → 上游 LLM；
3. LLM 返回工具调用 → 设备端在沙箱 `work/` 内执行（读文件/抓网页）；
4. 结果回填 → 再问 LLM → 最终中文回答；
5. 可选：`POST /api/task` 投递后台任务，`GET /api/task/{id}` 轮询。

## 安全边界

- 文件工具锁定在 `AGENT_WORKDIR`，路径越界直接拒绝；
- 设备不保存上游 Key，只持有可吊销的 `DEVICE_TOKEN`；
- 网关按设备限流/配额（v0.2）；
- 不默认开启 shell 执行（高风险能力要显式开关）。
